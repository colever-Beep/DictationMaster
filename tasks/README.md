# 听写任务（用户数据文件夹）

本目录由「听写助手」的 GitHub 同步功能读写，存放教师布置的听写任务。

- **文件名**：`{task_id}.json`，内容为自包含 JSON（词表快照 + 报读参数 + 截止日期），
  教室端拉取后无需原词表即可直接听写。
- **教师端（上传）**：「布置听写」→「上传到 GitHub」，或「管理布置」→「上传全部到 GitHub」。
- **教室端（拉取）**：「管理布置」→「从 GitHub 拉取」，按任务 ID 去重导入本地。

> 请勿手工改动文件结构；如需撤销某个任务，删除对应的 `.json` 文件即可。
> 本目录路径可在「设置 → GitHub 同步 → 任务目录」中修改（默认 `tasks`）。
